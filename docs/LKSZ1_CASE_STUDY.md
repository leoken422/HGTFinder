# LKSZ1事例評価

入力はAP031572.1のDFAST全3,285 CDS。GTDB R232でqueryはRS_GCF_040436315.1、属はSynechocystisです。参照はGTDB公式全種代表の全タンパク質です。

|判定|距離平均のみの基本判定|v0.1標準：同属最良ヒット除外|
|---|---:|---:|
|候補|3,067|1,148|
|非候補|31|1,950|
|保留|187|187|

保存済みTop100の再評価で1,919 CDSが候補から外れました。検索と距離平均は変更していません。

|遺伝子|query ID|平均|標準条件の判定|
|---|---|---:|---|
|nifEN融合|OLK001_02790|3.7980|candidate|
|nifK|OLK001_02820|3.6837|candidate|
|nifD|OLK001_02830|3.7143|candidate|
|nifH|OLK001_02840|3.6465|candidate|
|nifB|OLK001_02870|3.8283|candidate|

対象領域288,700–318,407 bpの34 CDSは31候補・3保留。領域全体を独立した34件のHGT真陽性とは数えません。

folP_1（OLK001_00010）は距離平均3.24ですが、最良ヒットが同属Synechocystis（408 bit、異属最大395 bit）のため標準条件では非候補です。nifHは異属最良546 bitが同属最大500 bitを上回るため候補に残ります。

## 既存ツールとの比較

保存された同一入力の予備試験ではHGTector2が主要5件中4件、134/3,285 CDSを候補としました。AlienHunter標準の予測領域はnifHとnifBに重なりました。HGTFinderが5件を拾う一方で、全ゲノムの候補も多いことに注意が必要です。

HGTector2の134候補のうち、HGTFinder標準でも候補なのは79件で、55件は同属最良ヒット条件で除外されます。HGTector2はシアノバクテリア限定208ゲノムのNCBI分類DBを使用しており、GTDB全種代表DBを使う本解析とアルゴリズムだけを比較した結果ではありません。

## パンゲノムとの関係

関連プレプリントの32株パンゲノムでは主要nifファミリーはLKSZ1のみのcloudとして報告され、今回の候補判定と整合します。ただしpersistentにも候補が残ります。パンゲノムの区分はHGTの真陽性・真陰性ラベルではありません。

関連プレプリント：https://doi.org/10.64898/2026.04.18.719408

この事例は検出精度のベンチマークではなく、HGT確定・供与体確定を意味しません。参照DBや第三者の本文・補足ファイル、既存ツールのコード・モデルはこのリポジトリへ同梱していません。
